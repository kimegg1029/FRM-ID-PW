# FRM ID/PW

개인용 Samsung Biologics 장비 계정 관리 PWA입니다.

## GitHub Pages 배포
1. 저장소 Settings → Pages로 이동합니다.
2. Build and deployment에서 Deploy from a branch를 선택합니다.
3. Branch `main`, folder `/ (root)`를 선택하고 Save 합니다.
4. 배포 주소: https://kimegg1029.github.io/FRM-ID-PW/

## 기능
- MIXER / MCS / VAL / ETC·공용 장비 분류
- MIXER 기본 Tag No. 5개 사전 등록
- Tag No. 통합 검색, 계정 추가·수정·삭제
- ID/비밀번호 복사 및 표시, 비밀번호 변경일과 로그인 성공일 기록
- 오프라인 캐시 지원

## 데이터 및 보안
계정 정보는 브라우저 LocalStorage에 저장되며 서버로 전송되지 않습니다. LocalStorage는 암호화 저장소가 아니므로 회사 보안 정책을 확인하고 실제 사내 비밀번호 저장 가능 여부를 판단해 주세요. 브라우저 데이터 삭제 또는 기기 변경 시 데이터가 사라질 수 있습니다.

캐릭터 비주얼은 사용자가 제공한 INNO·CELL-O·CHO 이미지의 색상과 배치를 참고해 앱에 맞춘 벡터 일러스트로 제작했습니다.
